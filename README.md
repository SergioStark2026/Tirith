# OpsCore

Renacimiento del antiguo prototipo Tirith como producto independiente y genérico para operaciones y mantenimiento de instalaciones.

## Objetivo
Centralizar activos, incidencias, preventivos, documentación, stock, mejoras, consumos y contactos técnicos en una aplicación simple y útil desde móvil.

## Estado
Prototipo funcional recuperado y rebrandeado. Esta rama es de staging y se copiará a un repositorio privado limpio `TheBoltLab/OpsCore` para no arrastrar el historial legacy.

## Probar
Abrir `index.html` en un servidor estático. La versión web incluye manifiesto PWA y service worker para instalación local cuando el navegador lo permita.

Antes de desarrollar, leer `PRODUCT.md`, `WORKFLOW.md` y `AGENTS.md`.
