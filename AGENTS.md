# AGENTS.md — OpsCore

## Objetivo
Convertir el prototipo recuperado en una aplicación mantenible y publicable sin arrastrar referencias ni datos del proyecto legacy.

## Reglas
- No introducir nombres, datos, marcas, ubicaciones o información de la empresa de origen.
- No añadir backend, servicios de pago ni credenciales sin aprobación.
- No almacenar API keys de producción en el cliente.
- Mantener cambios pequeños y reversibles.
- Preservar exportación/backup de datos.
- Priorizar uso móvil y offline.

## QA mínimo
- Flujos principales.
- Persistencia local.
- Exportación/importación.
- Cálculos de ROI/consumos.
- Estados vacíos y errores.
- Instalación PWA.
- Revisión de referencias legacy antes de cada release.
