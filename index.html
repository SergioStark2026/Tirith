Reglas del centro de mando

GitHub es la fuente de verdad del código. BoltLabHub solo resume estado, fase, CI y siguiente acción. No guardará secretos ni tokens en el navegador. La automatización con datos privados de GitHub se añadirá más adelante mediante una integración segura.
Prototipo de staging. Antes de publicarlo se moverá a un repositorio limpio e independiente.
